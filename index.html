Pengaturan Supabase

Isi URL + Anon Key dari Supabase → Settings → API. Jangan pakai service_role di frontend.

Jika Supabase terisi, data TP/Soal/Paket/Siswa akan dicoba simpan ke tabel Supabase. Jika gagal / kosong, otomatis fallback ke LocalStorage (Demo) agar app tetap jalan.

SQL & Cara Pasang di Web Kamu

Cara pasang file ini di web kamu:

  1. Simpan file ini sebagai index.html
  2. Upload ke hosting (Netlify / Vercel / cPanel / GitHub Pages / hosting sekolah)
  3. Buat project Supabase → SQL Editor → jalankan SQL di bawah → Run
  4. Storage → New Bucket → soal-images (Public)
  5. Settings → API → copy URL + Anon Key → paste di menu Supabase di app ini → Simpan
  6. Pengaturan Sekolah → Matikan Mode Demo → Hapus akun demo → buat akun asli
